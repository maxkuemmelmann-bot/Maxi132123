# Aufnahmeplan: In dieser Stadt hat jeder ein Haustier, außer mir

## So nimmst du auf
1. Starte ein **Stadt-Rollenspiel** in Roblox (z. B. Brookhaven oder ein ähnliches).
2. Nimm für jede Szene einen kurzen Clip auf, **5–8 Sekunden**:
   - **PC:** Windows-Taste + Alt + R (Xbox Game Bar) startet bzw. stoppt die Aufnahme
   - **Handy:** Bildschirmaufnahme im Kontrollzentrum
3. **Wichtig:** Das Video wird hochkant (9:16) zugeschnitten, links und rechts fällt viel weg.
   **Halte deinen Avatar immer in der Bildmitte** und zoom etwas näher ran.
4. Nenne die Clips `01.mp4`, `02.mp4` ... und lege sie in **diesen Ordner**.
5. Keine Musik oder Stimme nötig, Erzählerstimme und Untertitel macht das Programm.

> Tipp: Gib deinem Avatar ein auffälliges Outfit und lass es in allen Clips gleich.
> Wichtig: Kein fremdes Video nachbauen. Eigene Story = Original-Content, den TikTok auch bezahlt.

## Szenen
| Datei | Was soll man sehen? |
|---|---|
| `01.mp4` | Dein Avatar steht allein auf der Straße, andere Spieler mit Haustieren laufen vorbei |
| `02.mp4` | Haustiere in der Stadt: Hund, Katze, Pferd (falls die Map Haustiere hat), sonst andere Spieler |
| `03.mp4` | Dein Avatar steht im Haus, gegenüber ein anderer Avatar (die Mutter) mit verschränkten Armen |
| `04.mp4` | Dein Avatar hebt einen Stein bzw. Gegenstand auf oder steht neben einem Felsen |
| `05.mp4` | Dein Avatar läuft langsam die Straße entlang und trägt etwas, er springt ab und zu (schwer!) |
| `06.mp4` | Andere Avatare stehen um deinen herum (gern Freunde fragen, ob sie mitspielen) |
| `07.mp4` | Ein großer Platz bzw. eine Bühne in der Stadt |
| `08.mp4` | Haustiere bzw. Avatare, die springen und tanzen (Emotes nutzen) |
| `09.mp4` | Dein Avatar steht ganz still neben einem Tisch, nichts passiert |
| `10.mp4` | Andere Avatare starren deinen Avatar an (gern mit Überraschungs-Emote) |
| `11.mp4` | Dein Avatar jubelt, die anderen klatschen bzw. tanzen (Emotes) |
| `12.mp4` | Die Stadt bei Nacht, leere Straße, die Kamera fährt langsam durch |
