# Aufnahmeplan: In dieser Stadt hat jeder ein Auto, außer mir

## So nimmst du auf
1. Starte ein **Stadt-Rollenspiel** in Roblox (z. B. Brookhaven oder ein ähnliches).
2. Nimm für jede Szene einen kurzen Clip auf, **5–8 Sekunden**:
   - **PC:** Windows-Taste + Alt + R (Xbox Game Bar) startet bzw. stoppt die Aufnahme
   - **Handy:** Bildschirmaufnahme im Kontrollzentrum
3. **Wichtig:** Das Video wird hochkant (9:16) zugeschnitten, links und rechts fällt viel weg.
   **Halte deinen Avatar immer in der Bildmitte** und zoom etwas näher ran.
4. Nenne die Clips `01.mp4`, `02.mp4` ... und lege sie in **diesen Ordner**.
5. Keine Musik oder Stimme nötig, Erzählerstimme und Untertitel macht das Programm.

> Tipp: Gib deinem Avatar ein auffälliges Outfit und lass es in allen Clips gleich.
> Wichtig: Kein fremdes Video nachbauen. Eigene Story = Original-Content, den TikTok auch bezahlt.

## Szenen
| Datei | Was soll man sehen? |
|---|---|
| `01.mp4` | Dein Avatar steht am Straßenrand und schaut traurig, im Hintergrund fahren Autos vorbei |
| `02.mp4` | Dein Avatar rennt auf dem Gehweg, Autos überholen ihn |
| `03.mp4` | Ein Haus mit mehreren Autos davor (Kamera langsam darüber schwenken) |
| `04.mp4` | Dein Avatar steht in seinem Zimmer bzw. Haus und springt kurz (freut sich übers Ersparte) |
| `05.mp4` | Dein Avatar vor einem Autohaus oder Parkplatz mit teuren Autos, er dreht sich enttäuscht weg |
| `06.mp4` | Dein Avatar rennt einen Hügel oder eine Straße hoch (gern bei Nacht oder Regen, falls die Map das kann) |
| `07.mp4` | Eine große Straße oder ein Platz in der Stadt, viele Autos (Ankündigung des Rennens) |
| `08.mp4` | Viele Autos nebeneinander, dein Avatar steht zu Fuß daneben |
| `09.mp4` | Autos stehen dicht hintereinander (Stau), nichts bewegt sich |
| `10.mp4` | Dein Avatar rennt an den stehenden Autos vorbei und durch einen Park |
| `11.mp4` | Dein Avatar steht neben einem Sportwagen und springt jubelnd |
| `12.mp4` | Dein Avatar sitzt im Sportwagen und fährt sofort gegen etwas bzw. bleibt stehen |
